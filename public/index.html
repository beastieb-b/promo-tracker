How It Works

1
Source Scan — Scans the monthly promo threads on r/postmates and r/UberEATS plus the USCardForum coupon topic, and extracts codes for existing customers (Uber Eats codes work on Postmates too).
2
Code Applier — Opens Postmates in a background Chrome window, enters each queued code and records the result. Up to a few codes per run, a couple of minutes apart, to avoid rate limits. New codes are applied right away when rate limits allow.
3
Uber Eats Fallback — Codes Postmates rejects (except "Code expired") are retried on Uber Eats.
4
Savings & Regions — Region-locked promos (valid only in another area) don't count toward your savings. A code applied in the last few days isn't re-queued.
5
Monthly Reset — When a new monthly thread appears, that month's results are archived and a fresh month starts; the source catalog keeps its monitoring data.
